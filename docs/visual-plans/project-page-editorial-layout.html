Clean editorial layout for /projects/[id]

Replace mixed card widgets with one calm reading system: big hero, active side nav, label-and-text rows, soft panels, and a next-project card.

Why

Every section of the case-study page uses a different widget: cards, green and yellow bars, a bar chart, numbered badges, and a timeline. The text is small, and the section numbers add noise. The page reads like a component demo instead of a story.

Direction: a Read-mode editorial page. It uses only a few treatments, repeated everywhere: a large hero, one text column, label-and-text rows, one soft panel style, and a side nav that shows your place.
