Changes

LayoutA framed card with an inset image at the banners' real 2:1 shape, so nothing is cropped. The tech names become a small line above the title. The "Role" block is removed; it is still shown on the detail page.
ClickingThe whole card opens the project story (a stretched title link). The live demo or repository link stays a separate small pill above it. Keyboard focus rings the whole card.
MotionCard lift and shadow, cursor spotlight (kept), slow image zoom, a corner arrow badge that fades in, and the "Read the story" arrow slides. All turned off for visitors who prefer reduced motion.
Design and UIUX cardsSame framed style and hover motion. Their links stay as they are, so the existing tests still pass.
