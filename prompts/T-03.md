# Objective

## Add a UIUX Projects Tab with Card Grid and Fluid-Width Detail Pages

---

## Role

You are a front-end developer working on the user's portfolio website codebase. Approach this objective with the mindset, vocabulary, and priorities of that role.

---

## Description

The project section of the portfolio currently organizes work into tabs, including a Development section and a Graphic Designs section. The goal is to introduce a new tab dedicated to UIUX, showcasing the UIUX design projects the user has built. The two existing apps, Remindly and Spillr, already live in the portfolio under the Development section and their respective case studies, and their visual assets are stored at `public/assets/remindly` and `public/assets/spillr`. In the new UIUX tab, these two apps should be presented as cards, mirroring the card layout used by the Graphic Designs section. Clicking a card's "View" action should navigate to a separate page for that project, which displays all of its screens using a fluid, hugging width rather than a fixed width.

---

## Primary Objective

Add a new UIUX tab to the project section that presents Remindly and Spillr as cards in the same style as the Graphic Designs cards, with each card's "View" action linking to a dedicated project page that displays all screens at a fluid, non-fixed width.

---

## Secondary Objectives

- Reuse the existing Graphic Designs card pattern so the new UIUX cards look and behave consistently with the rest of the portfolio.
- Create dedicated detail pages for Remindly and Spillr that display all of each app's screens.
- Integrate the assets located at `public/assets/remindly` and `public/assets/spillr` into the new UIUX tab and detail pages.

---

## Success Criteria

- A new UIUX tab is present in the project section.
- Remindly and Spillr render as cards within that tab, visually and behaviorally consistent with the Graphic Designs cards.
- Clicking "View" on either card navigates to a per-project page.
- Each detail page displays all screens for the project using hugging (fluid) width, not a fixed width.

---

## Constraints

- The card presentation in the UIUX tab must match how the Graphic Designs section shows its cards.
- The detail page layout must use hugging width (fluid, content/viewport-adaptive) rather than a fixed width.
- Assets must be sourced from the existing paths `public/assets/remindly` and `public/assets/spillr`.

---

## Context & Dependencies

- Remindly and Spillr already exist in the portfolio under the Development section and case studies; the new UIUX tab surfaces these same projects as design work.
- The Graphic Designs section already implements the card pattern that the new UIUX cards should replicate.
- Screen/visual assets for both apps are already available at `public/assets/remindly` and `public/assets/spillr`.

---

## Supporting Tasks

### UIUX Tab & Card Grid
- Add a new "UIUX" tab to the existing project section.
- Add card entries for Remindly and Spillr within the tab, matching the Graphic Designs card layout and behavior.
- Add a "View" action to each card that navigates to the project's detail page.

### Detail Pages
- Create a dedicated page for Remindly that displays all of its screens.
- Create a dedicated page for Spillr that displays all of its screens.
- Ensure both detail pages use hugging (fluid) width for the screen display, not a fixed width.

### Asset Integration
- Wire up the card and detail-page visuals using the assets from `public/assets/remindly` and `public/assets/spillr`.
