# Objective
## Revise the Designs Tab into Categorized Development Cards and Gallery Pages

---

## Description
Revise the portfolio’s Designs tab to organize the available design images into categorized cards. The categories should include Social Media Designs, Anime Shoes Mockups, and Amway Flyers. Each category card should provide a “View Designs” button and support navigation when the card itself is clicked. Selecting a category should open a separate gallery page that displays the designs belonging to that category.

## Primary Objective
Update the Designs tab to display categorized design cards that link to dedicated gallery pages for each design category.

## Secondary Objectives
- Organize the portfolio designs into the following categories:
  - Social Media Designs
  - Anime Shoes Mockups
  - Amway Flyers
- Make each category card clickable.
- Add a “View Designs” button to each category card.
- Display the corresponding designs on a dedicated gallery page after a category is selected.

## Success Criteria
- The Designs tab displays one card for each specified category.
- Each card can be opened by clicking either the card itself or its “View Designs” button.
- Each category navigates to its own gallery page or category-specific gallery view.
- The gallery displays the designs associated with the selected category.
- The Amway Flyers gallery uses the assets located in `public\assets\amway-fliers`.
- Existing portfolio designs and named projects remain preserved unless explicitly removed.

## Context & Dependencies
- The portfolio already contains a Designs tab.
- The project uses assets stored in the public assets directory.
- New Amway Flyers assets are located at `public\assets\amway-fliers`.
