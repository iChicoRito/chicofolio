# Objective
## Add Development and Design Tabs to the Projects Section

---

## Role
You are a front-end developer. Approach this objective with a focus on clear navigation, consistent layout, accurate presentation of project imagery, and coordinated use of subagents.

---

## Description
Update the Projects section on the index page to support separate Development and Design project views. Add tab controls on the same row as the “02 - Projects” heading, aligned to the right, allowing users to switch between the two categories. Preserve the current projects as Development projects, and display graphic design work, including social media designs, under the Design tab. Use the design assets located in `public\assets\social-media-designs`, ensuring their square format is maintained. During planning and implementation, coordinate subagents to explore the codebase and complete independent changes efficiently without file-editing conflicts.

---

## Primary Objective
Implement Development and Design tabs in the index page’s Projects section so users can switch between development projects and graphic design work.

---

## Secondary Objectives
- Keep the existing project entries under the Development tab.
- Add the social media design images under the Design tab.
- Place the tab controls on the right side of the “02 - Projects” heading row.
- Ensure every design card’s image container uses a 1:1 aspect ratio.
- Use subagents during both planning and implementation.

---

## Success Criteria
- The Projects section includes Development and Design tabs.
- The tabs appear on the same row as “02 - Projects” and are aligned to the right.
- The Development tab displays the existing development projects.
- The Design tab displays images from `public\assets\social-media-designs`.
- All design image containers maintain a square 1:1 aspect ratio.
- Multiple implementation subagents work on different files to avoid editing conflicts.

---

## Constraints
- Implementation subagents must edit different files to prevent conflicts.

---

## Context & Dependencies
- The current Projects section displays only development projects.
- Graphic design assets, including social media designs, are stored in `public\assets\social-media-designs`.
- All provided design images have a 1:1 aspect ratio.

---

## Supporting Tasks

### Planning and Exploration
- Use subagents to explore the codebase during the planning phase.
- Identify the files and components responsible for the index page, Projects section, project data, styling, and design assets.

### Parallel Implementation
- Use multiple subagents simultaneously during implementation.
- Assign each implementation subagent to a different file to prevent editing conflicts.
- Coordinate the independent changes so they collectively implement the requested functionality.

### Tab Navigation
- Add Development and Design tab controls to the Projects section.
- Position the controls on the same row as the “02 - Projects” heading and align them to the right.
- Enable switching between the Development and Design project views.

### Project Organization
- Assign the existing project cards to the Development tab.
- Populate the Design tab with the available social media design assets.

### Design Card Layout
- Use images from `public\assets\social-media-designs` for the Design projects.
- Set each design card’s image container to a 1:1 aspect ratio so it matches the square source images.
